Jam2 experiment · DaisySP only

Synthesis capability showcase

A focused audition of DaisySP building blocks and small polyphonic voice designs. These clips do not alter Jam2 or claim to be finished production presets.

How to use this page

Start with the building blocks to learn the raw palette. Then compare each voice’s identical source-only and designed performances. The difference is the practical value of envelopes, layering, filtering, modulation, articulation and effects—not a different composition.

Render the experiment with build.cmd first.

Small complete instruments

Source versus voice design

Every pair uses the same notes and velocities. “Source only” exposes the basic oscillator or model; “Designed voice” uses a compact fixed signal path that Jam2 could drive automatically.
